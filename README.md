## 📖 项目概述

**91每日大赛 (`91mrdscn.cloud`)** 是一个聚焦于“日常原创竞技”与“赛制信息公开”的综合展示平台。我们通过标准化的规则公示流程与结构化的作品展陈方式，减少参赛信息不对称，让优质原创作品获得应有的曝光与公正评价。

## ✨ 核心功能

| 模块 | 功能说明 |
| :--- | :--- |
| **📋 赛事规则公示** | 集中发布每日参赛要求、原创声明规范、评分细则及截止时间 |
| **🖼️ 原创作品展区** | 汇聚每日参选的原创佳作，提供清晰的作者信息与作品详情展示 |
| **🏆 评选与榜单** | 实时更新每日评选动态、入围名单及优胜作品公示记录 |
| **📱 响应式体验** | 适配 PC 端与移动端设备，随时随地查阅最新赛况与规则公告 |

## 🎯 平台特色

1. **原创优先**：强调作品原创性与独立创作价值，维护健康的社区展示生态。
2. **公开透明**：所有赛事条款与评选周期均在站内前置公示，流程清晰可查。
3. **每日迭代**：保持高频日常更新节奏，持续沉淀高质量原创案例库。
